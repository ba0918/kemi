スレッドとチャット欄の置き方

採用: 案 A2 と、会話の並びだけが新しいものについていく決まり（2026-10-05）。仕様は docs/spec/agent-channel.md。モックと仕様が食い違うときは仕様が正しい。

エージェントとの往復（agent-channel）を実際に使った感想を受けて、スレッドとチャット欄をどこに置くかを決めるモック。ここで決めるのは、どこに置くかと、差分の中のスレッドとチャット欄の関係だけ。色・上部バー・ツリーは今のまま。

何を決めるか 設計変更 仕様判断（追従） 不具合

使ってみた感想
スレッドもチャット欄も狭い。返信が来たらそこへ追従したい。もっとチャットらしくしたい。画面の高さいっぱいに出して、すぐ畳めるようにしたい。
今の形
チャット欄は、ツリーの下の端から浮く小さな箱（幅 440px くらい、並びは 2〜3 件ぶん）。スレッドは差分の中の付箋色の吹き出しで、返信が増えると差分を大きく押し下げる。
不具合
ファイル全体へのコメントのスレッドが差分に食い込む。どの案でも、ファイル全体へのコメントはファイルの見出しの下に置き直す。
次の段階との関係
次に作る --live は、動いているページとスナップショットを同じ幅で並べる。会話の置き場所は、その横に並んでも邪魔にならないこと。

新しい返信への追従 仕様判断

今の仕様
kemi.md の R-LIVE: エージェントの返信・発言・状態は届いたらその場で出す。スクロール位置は変えない。
感想
返信が来たら、そこへ追従したい。
提案
会話パネルの中だけ、チャットでよくある決まりにする。並びの一番下を見ているときは、新しいものが来たら一番下へついていく。上のほうを読んでいるときは動かさず、下に「新しい返信 2 件 ↓」の札を出す（押すと一番下へ）。差分は今どおり動かさない。代わりに、ツリーのファイルと差分の札に、まだ読んでいない印を付ける。
仕様の変更
R-LIVE の例外に「会話パネルの並びは、一番下を見ているときだけ新しいものへついていく」を足す。agent-channel.md にも同じ一文を足す。
